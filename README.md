# AI Agents Lab

All my AI projects and studies in a lab — a monorepo of experiments, workshops, and production-style builds around LLM agents, RAG, and multi-agent systems, using frameworks like LangChain/LangGraph, CrewAI, and Google ADK.

## Projects

| Project | Description |
|---|---|
| [`21-ai-agentic-design-patterns/`](21-ai-agentic-design-patterns) | Code examples for 21 agentic design patterns (prompt chaining, routing, reflection, planning, memory, RAG, guardrails, and more), each implemented in both CrewAI and LangChain/LangGraph. |
| [`agent-forensic-doctor/`](agent-forensic-doctor) | RAG system for forensic case analysis and documentation retrieval, built with LangGraph, Qdrant, and OpenAI. |
| [`agent-rag-databricks/`](agent-rag-databricks) | RAG and SQL agent examples served on Databricks, with sample retail data (customers, products, sales). |
| [`agent-voice-retellai/`](agent-voice-retellai) | Bilingual (EN/PT) voice assistant prompts and knowledge base for Retell AI, built for e-commerce customer service. |
| [`ask-junior/`](ask-junior) | Microservices RAG assistant with observability, automated ingestion, and infra for vector DB, monitoring, and reverse proxy. |
| [`coding-ai-agents/`](coding-ai-agents) | Collection of agent-building exercises: LLM fine-tuning, MCP servers, CrewAI crews, Google ADK, LangChain/LangGraph pipelines, and framework-free implementations. |
| [`dataops-knowledge-hub/`](dataops-knowledge-hub) | Enterprise RAG demo combining Text-to-SQL (Postgres), vector search (Qdrant), and graph traversal (Neo4j) behind a router engine. |
| [`sales-assistant/`](sales-assistant) | WhatsApp AI sales agent for Brazilian e-commerce (Nuvemshop), built with LangGraph, pgvector, and Evolution API. |

Each project has its own `README.md` with setup instructions, architecture notes, and usage details.

## Stack

Python, LangChain / LangGraph, CrewAI, Google ADK, MCP, Qdrant / pgvector / Neo4j, PostgreSQL, Streamlit, Docker.
